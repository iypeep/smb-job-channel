# 内部工具 → 可公开仓库

**什么时候用**：手上有能跑的工具，想开源/公开，但它沾了生产数据、内网地址、密钥，或者有不想公开的实现细节。

**流程**：白名单导出（只挑源码与文档）→ 正则清洗（IP/主机名/机台名/项目代号/密钥）→ 逐文件 SPDX →
残留扫描必须 0 命中 → 许可与 NOTICE → 建仓推送 → 用 API 回验。

**记住**：清洗后要再扫一遍"反向证据"——不是只 grep 你替换过的东西，还要 grep 你**从没想过**的类别
（机台编号、工位名、人名拼音、共享盘名）。

---

**怎么用**：把 `SKILL.md` 交给你的 agent（例如「读 skills/sanitized-public-repo-release/SKILL.md 并按它执行」），或自己当 checklist 过一遍。
