# 自治代理：心跳、看护与自愈

**什么时候用**：机台上跑着轮询代理，出现"进程还在但不干活"、"作业不动也没人重启"、"两台实例互相杀"。

**核心**：心跳写**本地盘**、判定看本地心跳年龄、过期就 kill 进程树、看护再被计划任务兜底。

**最容易踩**：把心跳写在与主循环同一个网络盘上 —— 主循环卡死时心跳一起冻结，看起来"还活着"。

---

**怎么用**：把 `SKILL.md` 交给你的 agent（例如「读 skills/ompremote-bridge-selfheal/SKILL.md 并按它执行」），或自己当 checklist 过一遍。
